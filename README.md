# CloudTask AWS

CloudTask is a task management application built to learn and practice AWS cloud architecture.

## Project Goals

- Build a simple task management web application
- Deploy a frontend on AWS
- Build a serverless backend
- Store application data in AWS
- Implement authentication
- Monitor the application
- Manage AWS infrastructure using Infrastructure as Code

## Planned AWS Services

- Amazon S3
- Amazon CloudFront
- AWS Lambda
- Amazon API Gateway
- Amazon DynamoDB
- Amazon Cognito
- Amazon CloudWatch
- AWS IAM
